# Landing page starter — intentionally unfinished

Place this folder at landing/ in your existing repository. Brief: https://code-and-design.org/1/assignments/project-landing/.

Define one audience, offering, and useful action. Replace every instructional sentence and complete the hero, three benefits/features, details, and footer. Plan in two Figma frames, then build one HTML document that adapts between widths. The starter does not implement your layout or main action.

A main action can be an anchor linking to the actual #details section. Use a real trustworthy destination when linking elsewhere. Forms and animation are optional. No data collection service, backend, fake testimonials, or invented signup success is required. Identify fictional offerings as class concepts.

Build and test focus visibility, meaningful links, responsive arrangement, and source order. Keep your own design decisions and source notes concise. Deliver by December 2 before moving into portfolio curation. Scoped AI help requires prior source-check readiness and inspection/modification/testing of retained code.
