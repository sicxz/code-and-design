# Recipe starter — intentionally unfinished

Save index.html and styles.css together. Open index.html in a browser; edit the files in a text editor, save, and refresh. In CodePen, copy only the content between body tags into the HTML panel and copy styles.css into the CSS panel.

Read the recipe brief at https://code-and-design.org/1/assignments/project-recipe/. Replace every instructional sentence with real content. Complete the ingredient and step lists, add one relevant permitted image with alt text/credit, and add a real source link where appropriate. Build the type hierarchy and spacing yourself. The foundation CSS does not complete the design requirements.

Keep image files in a new images folder beside index.html. A local image link might be images/soup.jpg, with the exact case and extension of your own file. The download intentionally includes no borrowed photographs.

Student AI is off for this project. Be prepared to identify, predict, edit, and explain your own source. Keep these files for the manual migration into recipe/ in week 3.
