# Source recovery — intentionally faulty exercise

This is not valid final project markup and is not a solution. Two faults are intentional: the padding selector does not match the HTML class, and the second list item is outside its list.

First identify each fault and predict its effect. Correct the selector, save, and refresh. Then change padding from 1rem to 2rem and explain which space changes. Move the second list item inside the list and inspect the resulting structure.

Arrange a fresh independent source check with the instructor after practicing. They will select a new small change so you can demonstrate understanding rather than repeat memorized steps. Continue the next project with human help and documentation while recovering.

Full guidance: https://code-and-design.org/1/resources/source-checks/
