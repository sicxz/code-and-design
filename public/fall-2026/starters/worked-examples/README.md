# Worked examples — reference, not student submissions

responsive-cards.html is a complete original course example demonstrating semantic articles, anchor links, a shared card class, gap, and a two-column wide layout. It supplies a reference for October 28 and a possible HTML structure for the proposed 378 refresher.

form-practice.html demonstrates a visible input label and an explicitly local browser validity check. It has no submission endpoint, fetch request, persistence, or actual signup. Inspect it with the instructor; students do not need to author JavaScript or add a form to the required landing page.

Each HTML file is self-contained for offline use. These examples must remain labeled as worked examples and should never be distributed as finished student work.
