# October 28 practice — your starting files

Open index.html locally. The narrow layout starts with one column; at 48rem and wider it has three columns. Its card gap starts at 1rem.

1. Predict what changing gap to 2rem will do. Write the prediction before editing.
2. Change it, save, refresh, and compare.
3. Predict changing the wide repeat count from 3 to 2. Make the change.
4. Test at 375px and 1000px. Expect one column at the narrow width and two at the wide width, with the third card starting the next row.
5. Replace one card with a real field-guide entry and observe how its text length affects height.
6. Save these edited files. Do not submit the worked example as your own work.
