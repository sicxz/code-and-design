# Field guide starter — intentionally unfinished

Place this folder at field-guide/ in the existing portfolio repository. Read https://code-and-design.org/1/assignments/project-field-guide/.

Choose three related entries and consistent information fields. Complete one semantic article, then reuse its structure twice with unique IDs. Add navigation links whose hashes exactly match those IDs. Add a usable skip link and return-home link. Images are useful only when they help the reader and must have appropriate alt text and credit.

The stylesheet has foundation rules only. Build the shared card pattern, choose Grid or Flexbox, and add a media query based on when your content becomes crowded. Test narrow, intermediate, and wide widths, keyboard focus, and 200% zoom. Do not hide overflow before finding its cause.

You may compare the separate worked responsive-card example, but this starter does not contain the finished solution. Required core: three meaningful entries and working responsive navigation. No decorative-placement quota or extra case-study page.

Scoped AI generation is optional only after the independent construction/debugging check. Inspect, modify, and verify any retained help and disclose it briefly.
