# My DESN 368 portfolio

This is a growing starter. Replace the instructional text in index.html with a public introduction, and develop its styles gradually. Add completed projects to the list as the quarter proceeds. Keep this page at the repository root all term.

## Setup

Read https://code-and-design.org/1/resources/workflow/ for the reviewed workspace and publishing steps. Use the verified student-owned course repository established during the opening clone handoff; do not fork the instructor source. Keep project folders recipe/, tribute/, field-guide/, and landing/ alongside the root index.html and styles.css. Link to recipe/ from the root, and ../ from a project to return home. Add only the links whose projects you have actually created.

## Keep your course README

Copy only index.html and styles.css into your course repository's root. Preserve the existing course README and any assigned setup section. Add your live portfolio link, a compact project list, relevant sources, and a short AI disclosure when applicable to that README; do not replace it with this starter guide. Keep credits in one understandable place and link existing project notes rather than copying them several times. Never add personal IDs, grades, credentials, or private details.

## Final delivery

https://code-and-design.org/1/assignments/final-portfolio/

Four project entries, clear navigation, readable responsive presentation, and an independent source explanation are the core. You do not need a personal photo, social media accounts, a custom thumbnail system, or a separate reflection website.
