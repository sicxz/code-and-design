# One interaction check

**Weekly practice · 10 points · Due 2026-11-29 at 11:59 p.m. Pacific**

## Studio brief

Verify the landing page’s main action with the keyboard. This is the evidence from [week 9](/1/weeks/week-9/), not an additional project. Finish the same experiment begun in studio; it is included in that week's independent-work estimate.

## Build sequence

1. State what should happen when someone activates the main action.
2. Put the mouse aside and Tab to it; verify focus is visible.
3. Activate it and check the actual destination or behavior.
4. Repair one problem if found. If testing the optional form example, state explicitly that it sends no data.

## Source check

Name the HTML control, the expected result, observed result, and whether any data is sent. State one next repair or confirmation.

## Studio evidence

Submit in Canvas:

- **One artifact:** Your current landing page URL or files.
- **A brief explanation:** two to four sentences addressing the source check above.
- **One question or next step:** something specific enough for a person to respond to.

## Delivery check and rubric

Open the submitted link while signed out. If publishing or an online service is blocked, attach your current HTML/CSS or planning export with a one-sentence access note. Do not submit a private editor link that only you can open.

The [weekly rubric](/1/resources/rubrics/) awards 4 points for the requested experiment, 4 for its source explanation, and 2 for the question/next step and usable delivery. It does not grade the surrounding project's finish. No extra reflection page, repeated transcript, or decoration is required.

**AI allowance:** Optional scoped assistance after the source checks. Never claim an unconnected prototype sends a real signup.
