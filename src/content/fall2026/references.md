# References and documentation

Start with **[HTML.com](https://html.com/)**, our main HTML learning reference. Use its beginner guide to learn an idea, then try a small example in your own page. Keep the course's editor setup; you do not need another editor or hosting service to follow the HTML examples.

| Resource | Use it for |
| --- | --- |
| [HTML.com](https://html.com/) · main reference | Beginner explanations of tags, attributes, headings, paragraphs, links, images, and lists. |
| [MDN Web Docs](https://developer.mozilla.org/en-US/) | Check an element's meaning, attributes, nesting rules, and accessibility guidance. Start with the [HTML reference](https://developer.mozilla.org/en-US/docs/Web/HTML). |
| [DevDocs](https://devdocs.io/) | Quick documentation lookup while coding. Open its [HTML documentation](https://devdocs.io/html/) and search for the element you are using. |
| [References and documentation board](https://app.milanote.com/1TZEGF153WvYf7?p=5XZtUQNrEkQ) | Browse the course's collected links, including extra tutorials and typing practice. |

## Week 1: look up one thing, then use it

For [Week 1](/1/weeks/week-1/), focus on the HTML.com beginner sections about tags and attributes, headings and paragraphs, lists, links, and images. Leave tables, forms, and hosting for later.

1. Name the question: for example, “Should the recipe steps use `ul` or `ol`?”
2. Find the relevant explanation on HTML.com. Use MDN to check the element's meaning and allowed content; use DevDocs for a quick lookup.
3. Type a small example into your recipe. Change the content and explain what the tags do.
4. Save and check the result. Keep a link to a source you used in your project notes.

Documentation is available during the AI-free opening unit. Bring a specific question when an example and your result differ.

## When you need help

Start with the relevant guide and your own source. Tell a classmate or instructor what you expected, what happened, and what you tried. The board's [Asking for Help guide](https://www.theodinproject.com/lessons/foundations-asking-for-help) and [XY Problem explanation](https://xyproblem.info/) can help you describe the underlying problem.

Use Canvas discussions for course questions, the current Canvas course for office hours, or [email Travis](mailto:tmasingale@ewu.edu) for technical issues.
