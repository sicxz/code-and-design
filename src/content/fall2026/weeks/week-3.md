# Week 3 · Build a place for your work

**Monday, October 12 and Wednesday, October 14 · 1–3:30 p.m.**  
Optional AI explanations/debugging only after the foundation check; no page generation.

## Studio brief

Your CodePen recipe becomes the first project in a portfolio you keep all term. Move it once, by hand, so that folders, paths, commits, and publishing become understandable. Start a small tribute to a person, collective, place, or creative practice you can describe accurately.

## Build sequence

Each day: reconnect 1:00–1:15; demonstration 1:15–1:40; guided work 1:40–2:10; break 2:10–2:20; build 2:20–3:05; source exchange 3:05–3:25; save 3:25–3:30.

**Monday: publish one manual migration.**

1. Follow [One workspace](/1/resources/workflow/). Open the verified student-owned course repository established during the opening handoff, add the root portfolio starter, and create `recipe/index.html` and `recipe/styles.css`.
2. Move your own HTML and CSS from CodePen. The full local document needs its `head`, viewport metadata, and stylesheet link. CodePen had supplied part of that surrounding document for you.
3. Put the recipe link on the portfolio home. From the recipe, add `<a href="../">Back to portfolio</a>`.
4. Commit, push, and enable GitHub Pages from the `main` branch's root. Open the actual deployment URL and test both directions.
5. Change one heading, commit again, and verify the new text online. Point to the commit that contains it. If an account or service is blocked, keep the same folder layout locally and bring the error; do not add a second hosting service.

**Wednesday: plan the tribute at the moment you need Figma.**

1. Read the [tribute brief](/1/assignments/project-tribute/). Choose a subject with credible source material and one usable image or original illustration.
2. Write a short introduction and three key moments or contributions in your own words. Record two sources. Avoid collecting more content than you can organize on one page.
3. In Figma, create one wide frame and add the real title, image area, introduction, and highlights. Learn only frames, text, spacing, and simple fills today. A narrow pencil sketch is enough to plan what stacks.
4. Add a compact style tile: one heading/body type decision, text/background/accent colors, and a spacing choice. You may use a single font family. This is working planning evidence, not a second graded design project.
5. Create `tribute/index.html` and `tribute/styles.css` using the [starter](/fall-2026/starters/tribute.zip). Mark up your real content before attempting a side-by-side layout. Add its link to the portfolio when it is useful to visit.

## Source check

From `tribute/index.html`, where does `../recipe/` lead? How would `recipe/` differ? Trace the folders on paper, then test. Explain the difference between saving locally, committing, pushing, and seeing the published page.

## Studio evidence

Submit [Publish one manual change](/1/assignments/practice-03/) with the live page, the relevant commit URL, two-to-four sentences tracing the change, and one question. No separate README redesign is required.

## Delivery check

The home → recipe → home route must work online. Keep source credits close to the work. Confirm the tribute sketch contains real content and predicts its reading order before next week's layout work. If the foundation check remains incomplete, continue with docs and human help and use the scheduled recovery attempt.
