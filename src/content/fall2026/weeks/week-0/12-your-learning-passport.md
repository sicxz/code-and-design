Your Learning Passport is one small file that holds the lessons you marked complete and the name you gave the companion. This site has no login, so the file is how your place moves with you from one computer to another. The marks are your own place markers, not a grade.

## Mark your place

At the bottom of each lesson, select **Mark as complete**. The button turns green, and the lesson's circle in the list turns green. The mark is saved in this browser only.

## Save a copy in Canvas

1. Open the [Learning Passport](/1/passport/) page. The link is also at the bottom of every page.
2. Select **Export the passport**. Your browser downloads a file named `desn368-passport.json`.
3. Upload that file to [Save Point: Learning Passport](https://canvas.ewu.edu/courses/1925415/assignments/11776597) in Canvas. Canvas keeps it for you.

Upload a new copy whenever you want a fresh save. It is not graded.

## Pick up on another computer

1. In Canvas, open **Save Point: Learning Passport** and download your last file.
2. Open the [Learning Passport](/1/passport/) page on the new computer.
3. Select **Choose a passport file** and pick the file you downloaded.
4. If this browser already has marks, choose **Keep this browser**, **Use the file** or **Merge both**.

## On a shared or lab computer

Export first. Then select **Remove from this browser**, so the next person starts clean.
