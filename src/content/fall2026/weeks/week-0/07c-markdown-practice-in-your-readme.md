## Open your README

1. Open your repository from the **Workspace** link in the [Week 0 Canvas module](https://canvas.ewu.edu/courses/1925415/modules). Check that its address ends with your GitHub username and that GitHub shows **Private**.
2. Open `README.md` and select the pencil icon to edit it. If you made Wednesday's profile-URL edit, keep it; you do not need to repeat that step.
3. Go to the **end** of the file, after its existing sections. Add a new heading: `## Markdown practice`. Keep it below `<!-- START-HERE:end -->` if that marker is still present. The cleanup step removes the setup block between the two `START-HERE` markers, so your new section must be outside it.

## Show each feature in your own words

Use a short note about something you might make in this course. Include everything the Canvas assignment asks for:

1. Make some words italic with `*word*` and some bold with `**word**`.
2. Add a smaller heading, such as `### One idea`, below `## Markdown practice`.
3. Add an inline link such as `[course site](https://code-and-design.org/1/)` and a reference-style link. For the second kind, write `[course site][course]` in a sentence and put `[course]: https://code-and-design.org/1/` on its own line below. Change the link text or destination if another source fits your note better.
4. Add an image with meaningful alternative text, using the pattern `![description of the image](image-path-or-URL)`. You can use a picture you made or one you have permission to use. If it came from someone else, name and link its source next to it. Check that the image actually appears in GitHub's preview.
5. Add a blockquote starting with `>`, an unordered list starting with `-`, and an ordered list starting with `1.`.
6. Write two paragraphs with a blank line between them. In one paragraph, make a hard line break: after its first line, press **Space twice**, then **Return**, and continue on the next line. In Preview, those two lines should stay in the same paragraph but appear on separate lines.

These are examples of syntax, not words to copy as your answer. The [Markdown lesson](/1/weeks/week-0/markdown/) explains why source and preview look different. If a mark does not render as you expected, change the source and preview it again.

## Preview, save, and submit

1. Select GitHub's **Preview** tab above the editor. Look for each heading, link, image, quote, list, paragraph, and line break. Return to **Edit** to revise anything that did not render as intended.
2. Commit the README with a message such as “Add Markdown practice.” Reopen the repository's front page and confirm the section appears near the end of the rendered README.
3. Copy your repository URL from the address bar. [Submit it to APPLY: Markdown Tutorial in Canvas](https://canvas.ewu.edu/courses/1925415/assignments/11775193) when the section is ready. Check that assignment's **Due** field for the deadline.

When you later follow the cleanup step in your README, delete only the setup block it names. Then reopen the rendered README and confirm **Markdown practice** remains. An older cleanup guide may list nine sections; your new practice section is an additional section.
