**Repository.** A repository holds your project files and their recorded history.

**File and folder.** A file holds content, such as your introduction. A folder groups files, such as the work inside `week-0`.

**Commit.** A commit is a saved, named change to the files in your repository. When you save a file in GitHub's editor, you make a commit.

**Your repository.** Yours is private. Only you and the instructor can open it. It lives in the class organization on GitHub, `code-and-design-teaching`. Its name ends with your GitHub username. You get it in the lesson Get your workspace.

**The template.** The template is the instructor's starting copy. Every student's repository begins as a copy of it. You never fork it or change it.

**In-class check:** On the instructor's screen, point to one file and one folder. Then name the commit that last changed the file.
